This guide shows the request shape you will use with the AgentBody Gateway API. Before sending a production request, create an API key through the AgentBody Console.

## Prerequisites

You need:

- An AgentBody account and a valid API key.
- A terminal with `curl`, or an HTTP client of your choice.
- The endpoint and request schema from the [API reference](/api-reference/introduction).

## Send an authenticated request

Set your key in your shell. Do not commit this value or add it to public documentation.

```bash
export AGENTBODY_API_KEY="<AGENTBODY_API_KEY>"
```

Then use the endpoint, method, and request body documented for the operation you want to call:

```bash
curl --request <METHOD> \
  --url "https://api.agentbody.io/<PATH>" \
  --header "Authorization: Bearer $AGENTBODY_API_KEY" \
  --header "Content-Type: application/json" \
  --data '<REQUEST_BODY>'
```

<Note>
  Replace the placeholders with values from the API reference. The Gateway-owned OpenAPI contract is the authoritative source for methods, paths, authentication details, and request schemas.
</Note>
