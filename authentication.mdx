---
title: "Authentication"
description: "Authenticate AgentBody Gateway API requests with an API key."
---

Authenticate every API request using an API key issued through the AgentBody Console. Keep keys out of client-side code, version control, issue trackers, screenshots, and public documentation.

## Send the authorization header

Use the authorization scheme required by the [API reference](/api-reference/introduction). The following example shows the expected placeholder pattern:

```bash
curl --request <METHOD> \
  --url "https://api.agentbody.io/<PATH>" \
  --header "Authorization: Bearer <AGENTBODY_API_KEY>"
```

<Warning>
  Never expose an API key in browser code or a public repository. Send requests through a trusted server-side environment.
</Warning>

## Store keys securely

Use your deployment platform's secret manager or environment-variable configuration. Load the key at runtime on the server.

```bash
AGENTBODY_API_KEY=<AGENTBODY_API_KEY>
```

If you believe a key has been exposed, revoke it through the appropriate control plane and replace it before resuming requests.
