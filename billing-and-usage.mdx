title: "Billing and usage"
description: "Understand AgentBody usage before production rollout."
---

Usage and billing are managed by AgentBody. Review the Console for the current usage information and any account-specific limits available to your organization.

## Plan for variable usage

Usage can vary by operation, workload size, and service configuration. Design workflows to record the application-level activity that matters to you, such as completed tasks and request volume.

Avoid embedding fixed per-tool prices in applications or public documentation. Pricing and usage behavior can change as the Gateway evolves.

## Build operational safeguards

Use account-level budgets, internal alerts, and request limits appropriate to your application. Pair these safeguards with the retry guidance in [Error handling and retries](/errors-and-retries) so transient failures do not create unbounded request volume.
